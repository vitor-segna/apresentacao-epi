# EPI Guard - Apresentação

Este repositório contém os slides da apresentação do **EPI Guard**, um sistema inteligente e autônomo de monitoramento de EPIs desenvolvido para a **Facchini**.

## Funcionalidades
- Splash Screen corporativo com identidade visual Facchini.
- Transições animadas horizontais (deslizar para o lado).
- Apresentação em 5 slides cobrindo:
  1. Capa / Introdução do EPI Guard.
  2. O Painel Web Administrativo (PHP/JS).
  3. O Cérebro da Inteligência Artificial (Python/YOLOv8).
  4. Stack Tecnológica (Nginx, PHP, Python, PostgreSQL).
  5. Fluxo Geral de Funcionamento do sistema.

## Tecnologias Utilizadas
- HTML5, CSS3, Javascript.
- Font Awesome para ícones.
- Google Fonts (Outfit e Inter).
